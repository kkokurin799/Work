# Work

Личный контур руководителя продуктового направления: проекты запуска у клиентов, бэклог развития продуктов, сроки и напоминания.

Сейчас в репозитории проработка, по которой приложение можно собирать без повторного выбора границ.

- [Техническое задание](docs/TZ.md) — сценарии, экраны, поля, формат почты и Telegram, подсветка за 14 дней, приёмка.
- [Архитектура](docs/ARCHITECTURE.md) — сервис, модель данных, разбор сообщений, оповещения, развёртывание.

Оповещения идут в Telegram. Почта и Telegram принимаются как каналы, откуда поручение попадает в базу. Неразобранное сообщение остаётся во входящих, а не теряется.
