# Шаблоны форматов

Заполняй слоты в квадратных скобках. Слот без данных в брифе → оставить `[уточнить: ...]`, не додумывать.

## 1. Совместный пресс-релиз для СМИ (проект с заказчиком)

```
# [Заказчик] [автоматизировал / переводит / запустил ...] [процесс] [с помощью решений / вместе с / на решениях] «Диасофт»

[Заказчик] и компания «Диасофт» [дата] [завершили проект / запустили в опытно-промышленную эксплуатацию] [что]. Решение [охватывает / автоматизирует] [2–3 главных процесса] и [главный эффект].

Проект стал [этапом развития платформы заказчика / ответом на регуляторные требования]. [Нейтрально о прошлом: собственная система заменяется промышленным решением ...]. Ключевыми требованиями проекта стали [3 требования]. [Главный измеримый результат.]

Решение автоматизирует [перечень процессов]. В рамках проекта [настроен ЭДО / проверено N процессов / мигрированы данные].

«[Что было важно заказчику] ... [что получили] ... [один показатель]», – отметил(а) [Имя Фамилия], [должность] [организация].

Специалисты «Диасофт» [развернули, настроили, миграция, интеграция, консультации]. Комплекс развернут на [технологическая база одним предложением].

«[Сложность задачи] ... [подход] ... [значение для рынка/заказчика]», – отметил [Имя Фамилия], руководитель продуктового направления «[X]» компании «Диасофт».

[Дополнительные сервисы — отдельный абзац: что, зачем, регуляторный триггер с точной ссылкой; техническая связка систем — здесь, не в цитате.]

«[2–3 предложения только о дополнительных сервисах]», – отметил [Имя Фамилия], руководитель продуктового направления «[Y]» компании «Диасофт».

[Статус: сопровождение; переход в промышленную эксплуатацию — срок и условие.]

[Заказчик] и «Диасофт» планируют продолжить [развитие решения / сотрудничество] ...

---
О компании [Заказчик] — [блок предоставляет заказчик]
О компании «Диасофт» — см. стайлгайд, актуализировать
Контакты для СМИ: [пресс-служба заказчика]; pr@diasoft.ru
```

Распределение спикеров при трех цитатах: заказчик (приемка результата) → руководитель основного продукта (суть проекта) → руководитель дополнительного продукта (только свой сервис). Порядок цитат совпадает с порядком блоков текста.

## 2. Новость на сайте «Диасофт» (проектная)

То же, что релиз для СМИ, но: без справок «О компании» и контактов; финальная строка — «Для получения дополнительной информации заполните форму обратной связи». Допустимо 2 цитаты. Заголовок может акцентировать продукт: «... благодаря продукту «Диасофт»».

## 3. Продуктовая новость

```
# «Диасофт» [реализовал / расширил / добавил] [что] в [продукт]  |  # В [продукт] от «Диасофт» появился [что]

Компания «Диасофт» расширила возможности [«Продукт» (Digital Q.X)] [для кого], реализовав [что]. Новая функциональность [соответствует требованиям Банка России (указание от ДД.ММ.ГГГГ №...), вступающим в силу с ...] / [решает задачу ...].

[Что это дает клиенту: не нужно собственных доработок / единая точка ответственности / сокращение сроков.]

[Продукт] закрывает полный цикл [процесса], включая:
- ...;
- ...;
- ....

«[Архитектурный принцип / как спроектировано / как будет развиваться]», – отметил [Имя Фамилия], руководитель продуктового направления «[X]» компании «Диасофт».

[Итог: гибкость, адаптация под новые требования.] Для получения дополнительной информации заполните форму обратной связи.
```

## 4. Экспертная новость (конференция, колонка)

```
# «Диасофт» рассказал о [тема]  |  # Эксперты «Диасофт» рассказали о [тема]

[Дата] на [мероприятие] [кто] обсудили [повестка]. На мероприятии выступил [Имя Фамилия], [должность] компании «Диасофт». Он рассказал, [о чем].

[Тезис 1 — проблема рынка.] [Тезис 2 — что потребуется участникам.] [Тезис 3 — требования к технологиям.]

«[Принципы / позиция — 2–3 предложения]», – отметил [Имя Фамилия].

«Диасофт» развивает решение [«Продукт» (Digital Q.X)], помогая участникам рынка [что]. Об ИТ-решениях и трендах рынка эксперты компании рассказывают на отраслевых мероприятиях.
```

## 5. Кейс (для сайта / презентации / отраслевого СМИ)

Структура: Заказчик и контекст → Задача (нейтрально, через требования) → Решение (продукты, архитектура, интеграции) → Ход проекта (этапы, сроки, роли) → Результаты (таблица «было / стало» только по данным брифа) → Цитаты → Планы. Объем 600–1000 слов. Каждый результат — с единицей измерения и периодом.

## 6. Лендинг-блок продукта

- H1: что делает продукт для кого (≤ 70 знаков).
- Подзаголовок: главный результат + доказательство (кейс, рейтинг, число клиентов).
- 3–5 карточек «задача → как решает продукт».
- Блок «Соответствие требованиям»: регуляторные акты с номерами.
- Блок «Технологии»: микросервисы, импортонезависимость, Digital Q.DataBase, интеграции.
- Социальное доказательство: логотипы/цитаты только согласованных заказчиков.
- CTA: «Запросить демонстрацию», «Получить консультацию». Без «Купить сейчас».

## 7. Пост для Telegram / VK (по релизу)

3–6 коротких абзацев: факт → главный результат → одна цитата (сокращенная, согласованная) → ссылка на релиз. Без эмодзи-рядов; допустим один маркер-эмодзи в начале, если канал так оформлен. Хэштеги — только принятые в канале.

## 8. Сопроводительное письмо журналисту

Тема: `[Заказчик] и «Диасофт»: [суть в 6–8 словах]`. Тело: 2 предложения о новости, 1 — почему актуально для аудитории издания сейчас (регуляторный срок, тренд), предложение комментария спикера, вложение/ссылка. Подпись пресс-службы.
